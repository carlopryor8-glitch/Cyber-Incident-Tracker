\# Cyber Incident Tracker



\## Project Description



Cyber Incident Tracker is a Python command line application designed to record, organize, search, and track cybersecurity incidents. Examples of incidents include phishing emails, malware alerts, unauthorized access, and suspicious activity.



\## Features



\- Record new cybersecurity incidents.

\- View all recorded incidents.

\- Search incidents using keywords.

\- Update incident statuses.

\- View a summary report by severity and status.

\- Export incident reports to a CSV file.

\- Save incident records in a JSON file so they can be accessed later.



\## Technologies Used



\- Python 3

\- JSON for storing incident data

\- CSV for exporting reports

\- Python standard library modules



\## Requirements



Python 3 must be installed. No third-party packages are required.



\## How to Run the Program



1\. Open PowerShell or a terminal.

2\. Navigate to the project folder.

3\. Run the following command:



```powershell

python TermProject.py

```



4\. Choose an option from the menu and follow the prompts.



\## Project Files



\- `TermProject.py` — Main application source code.

\- `incidents.json` — Stores recorded incident data and is created automatically when needed.

\- `incident\_report.csv` — Exported incident report created when the CSV export option is selected.

\- `requirements.txt` — Lists project dependencies.



\## Limitations and Future Improvements



This project is an educational demonstration and is not a production security monitoring system. It does not automatically scan devices or verify whether reported incidents are real. Future improvements could include user authentication, encrypted storage, automated backups, and database integration.
